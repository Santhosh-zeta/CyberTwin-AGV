# Contributing

Thanks for your interest in CyberTwin-AGV! Issues and pull requests are welcome.

1. Fork the repo and create a feature branch.
2. Dashboard changes: `cd dashboard && npm ci && npm run lint && npm run build` must pass.
3. Keep commits focused and describe *why* in the message.
4. Open a pull request against `main`.

By contributing you agree your work is released under the [MIT License](LICENSE).
